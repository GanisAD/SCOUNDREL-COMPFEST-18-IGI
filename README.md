# ALTAR-52 (SCOUNDREL-COMPFEST-18-IGI)
A Roguelike deckbuilder card game built in Godot 4 with core mechanics inspired by Scoundrel.

---

## 📚 Pusat Dokumentasi & Onboarding Tim

Untuk anggota tim yang baru bergabung (khususnya **UI Programmer** dan **Sound Designer**), silakan merujuk ke dokumentasi di dalam folder [`docs/`](./docs/README.md):

* 🚀 **[Panduan Onboarding & Arsitektur Utama](docs/README.md)**: Gambaran umum arsitektur proyek, spesifikasi engine Godot 4, struktur direktori, dan aturan kontribusi.
* 🔊 **[Panduan Integrasi Audio & Matriks Suara](docs/AUDIO_INTEGRATION_GUIDE.md)**: Peta pemicu suara (SFX & BGM), konfigurasi AudioBus, dan panduan penggunaan `AudioManager`.
* 🎨 **[Panduan Arsitektur & Hierarki UI](docs/UI_ARCHITECTURE.md)**: Hierarki HUD (`BattleUI`), komponen reusable (`StatsUI`, `IntentUI`), dan State Machine interaksi kartu (`CardUI`).
* 📡 **[Katalog Sinyal EventBus](docs/EVENT_BUS_CATALOG.md)**: Kamus lengkap sinyal global dan payload data pada singleton `Events`.
